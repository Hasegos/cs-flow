Java — 이진 트리 노드 정의 및 삽입

/* ── 이진 트리 노드 ─────────────────────────────────────── */
public class TreeNode {
    int value;
    TreeNode left;
    TreeNode right;

    TreeNode(int value) {
        this.value = value;
    }
}

/* ── 레벨 순서로 채워 넣는 완전 이진 트리 구성 ─────────────── */
// 배열 인덱스 i의 자식은 2i+1(왼쪽), 2i+2(오른쪽)에 대응합니다.
public class BinaryTree {
    TreeNode root;

    public TreeNode buildFromArray(int[] values) {
        if (values.length == 0) return null;
        TreeNode[] nodes = new TreeNode[values.length];
        for (int i = 0; i < values.length; i++) {
            nodes[i] = new TreeNode(values[i]);
        }
        for (int i = 0; i < values.length; i++) {
            int leftIdx = 2 * i + 1;
            int rightIdx = 2 * i + 2;
            if (leftIdx < values.length)  nodes[i].left  = nodes[leftIdx];
            if (rightIdx < values.length) nodes[i].right = nodes[rightIdx];
        }
        root = nodes[0];
        return root;
    }
}

일반 이진 트리는 정렬 조건이 없으므로, 배열을 레벨 순서(Level-order)로 그대로 노드에 대응시켜 완전 이진 트리 형태로 구성할 수 있습니다.
BST(이진 탐색 트리)처럼 "왼쪽 자식 < 부모 < 오른쪽 자식" 조건이 없는 순수 구조라는 점이 다음 토픽인 BST와의 차이입니다.

Java — 전위 / 중위 / 후위 순회 (재귀)

/* ── 전위 순회: Root → Left → Right ─────────────────────── */
public void preorder(TreeNode node, List<Integer> result) {
    if (node == null) return;       // 재귀 종료 조건
    result.add(node.value);                 // 1. 루트 방문
    preorder(node.left, result);          // 2. 왼쪽 서브트리
    preorder(node.right, result);         // 3. 오른쪽 서브트리
}

/* ── 중위 순회: Left → Root → Right ─────────────────────── */
public void inorder(TreeNode node, List<Integer> result) {
    if (node == null) return;
    inorder(node.left, result);           // 1. 왼쪽 서브트리
    result.add(node.value);                 // 2. 루트 방문
    inorder(node.right, result);          // 3. 오른쪽 서브트리
}

/* ── 후위 순회: Left → Right → Root ─────────────────────── */
public void postorder(TreeNode node, List<Integer> result) {
    if (node == null) return;
    postorder(node.left, result);         // 1. 왼쪽 서브트리
    postorder(node.right, result);        // 2. 오른쪽 서브트리
    result.add(node.value);                 // 3. 루트 방문
}

/* ── 호출 예시 ──────────────────────────────────────────── */
List<Integer> result = new ArrayList<>();
preorder(root, result);
// result: [루트, 왼쪽 서브트리 전위, 오른쪽 서브트리 전위] 순서로 채워집니다.

세 순회 함수는 재귀 호출 순서만 다를 뿐 구조가 동일합니다.
result.add()를 어느 위치에 두느냐가 전위·중위·후위를 가릅니다.
각 재귀 호출은 호출 스택에 현재 노드를 쌓고, null을 만나면(리프의 자식) 스택을 거슬러 올라갑니다 — 시각화의 "스택 깊이"가 바로 이 호출 스택입니다.
시간복잡도는 모든 노드를 정확히 한 번 방문하므로 O(n), 공간복잡도는 재귀 호출 스택 깊이만큼인 O(h) (h = 트리 높이, 최악의 경우 편향 트리에서 O(n))입니다.

Java — 레벨 순회 (BFS, 참고)

/* ── 레벨 순회: 큐를 이용한 너비 우선 탐색 ──────────────── */
// 전위·중위·후위가 깊이 우선(DFS)인 것과 달리, 레벨 순회는 큐 기반 BFS입니다.
public void levelOrder(TreeNode root, List<Integer> result) {
    if (root == null) return;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();
        result.add(node.value);
        if (node.left  != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
}

재귀 대신 큐(Queue)에 자식 노드를 순서대로 넣고 빼면서 레벨 단위로 방문합니다.
트리의 폭(너비)이 넓을수록 큐가 커지므로 공간복잡도는 O(w) (w = 최대 레벨 너비)입니다.
레벨 순회는 이번 시각화의 핵심 범위는 아니지만, DFS(전위·중위·후위)와 BFS(레벨 순회)의 차이를 이해하는 데 참고가 됩니다.
