Java — BST 노드 정의 및 삽입

/* ── BST 노드 ───────────────────────────────────────────── */
public class BSTNode {
    int val;
    BSTNode left, right;
    BSTNode(int val) { this.val = val; }
}

/* ── 삽입: 루트부터 비교하며 null 위치를 찾아 삽입 ─────── */
public BSTNode insert(BSTNode root, int val) {
    if (root == null) return new BSTNode(val); // 삽입 위치
    if (val < root.val)
        root.left  = insert(root.left,  val);    // 왼쪽으로
    else if (val > root.val)
        root.right = insert(root.right, val);    // 오른쪽으로
    return root;                                   // 이미 존재하면 무시
}

/* ── 탐색 ────────────────────────────────────────────────── */
public boolean search(BSTNode root, int val) {
    if (root == null) return false;  // 탐색 실패
    if (val == root.val) return true; // 탐색 성공
    return val < root.val
        ? search(root.left,  val)
        : search(root.right, val);
}

삽입과 탐색 모두 현재 노드와 값을 비교해 왼쪽/오른쪽을 결정하는 동일한 패턴을 씁니다.
재귀 구조 덕분에 각 서브트리를 독립적으로 처리하며, 균형 잡힌 트리에서 높이는 log n이므로 평균 O(log n)입니다.

Java — 삭제 3케이스

public BSTNode delete(BSTNode root, int val) {
    if (root == null) return null;  // 값이 없음

    if (val < root.val) {
        root.left  = delete(root.left,  val); // 왼쪽 서브트리에서 삭제
    } else if (val > root.val) {
        root.right = delete(root.right, val); // 오른쪽 서브트리에서 삭제
    } else {
        // 삭제 대상 발견
        if (root.left  == null) return root.right; // Case 1,2: 왼쪽 없음
        if (root.right == null) return root.left;  // Case 2: 오른쪽 없음

        // Case 3: 자식 2개 → 중위 후계자(오른쪽 서브트리의 최솟값)로 대체
        BSTNode successor = findMin(root.right);
        root.val   = successor.val;                       // 값만 교체
        root.right = delete(root.right, successor.val); // 후계자 제거
    }
    return root;
}

private BSTNode findMin(BSTNode node) {
    while (node.left != null) node = node.left; // 가장 왼쪽 = 최솟값
    return node;
}

Case 1(리프): 자식이 없으므로 null을 반환해 부모와의 연결을 끊습니다.
Case 2(자식 1개): 남은 자식을 반환해 부모가 손자를 직접 가리키게 합니다.
Case 3(자식 2개): 중위 후계자(오른쪽 서브트리 최솟값)의 값을 현재 노드에 복사한 뒤, 후계자를 재귀적으로 삭제합니다.
후계자는 왼쪽 자식이 없으므로 Case 1 또는 2로 처리됩니다.
이 재귀 패턴은 BST 조건을 유지하면서 O(h) 시간 안에 삭제를 완료합니다.

Java — TreeMap으로 BST 활용

/* ── TreeMap: Red-Black Tree 기반 BST — 항상 O(log n) 보장 */
TreeMap<Integer, String> map = new TreeMap<>();

map.put(50, "root");
map.put(30, "left");
map.put(70, "right");

// 정렬 순서 보장
map.firstKey();          // 30  — 최솟값 O(log n)
map.lastKey();           // 70  — 최댓값 O(log n)

// 범위 탐색: 30 이상 70 미만 키를 정렬 순서로
map.subMap(30, 70).forEach((k, v) ->
    System.out.println(k + " → " + v)
);

// 50보다 작은 가장 큰 키 (전임자)
map.lowerKey(50);        // 30

// 50보다 크거나 같은 가장 작은 키 (후임자)
map.ceilingKey(50);     // 50

/* ── HashMap vs TreeMap 비교 ─────────────────────────────── */
// HashMap : 평균 O(1) 탐색/삽입, 순서 없음
// TreeMap : O(log n) 탐색/삽입, 정렬 순서 보장, 범위 탐색 지원

Java의 TreeMap/TreeSet은 Red-Black Tree를 사용해 편향 트리 문제 없이 항상 O(log n)을 보장합니다.
정렬 순서가 필요하거나 범위 탐색(subMap, headMap, tailMap), 전임자/후임자 조회가 필요하면 TreeMap을, 순서가 필요 없고 단순 탐색 속도만 중요하면 HashMap을 사용합니다.
