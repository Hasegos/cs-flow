Python — 접미사 배열 구성과 이진 탐색

def build_sa(s):
    return sorted(range(len(s)), key=lambda i: s[i:])   # 접미사를 사전순으로 정렬

s = 'banana'
sa = build_sa(s)
print(sa)                          # [5, 3, 1, 0, 4, 2]
print([s[i:] for i in sa])             # ['a', 'ana', 'anana', 'banana', 'na', 'nana']

def search(s, sa, p):
    lo, hi = 0, len(sa)
    while lo < hi:                      # p 이상인 첫 접미사
        mid = (lo + hi) // 2
        if s[sa[mid]:sa[mid] + len(p)] < p: lo = mid + 1
        else: hi = mid
    start = lo
    hi = len(sa)
    while lo < hi:                      # 앞 len(p)글자가 p보다 큰 첫 접미사
        mid = (lo + hi) // 2
        if s[sa[mid]:sa[mid] + len(p)] <= p: lo = mid + 1
        else: hi = mid
    return sorted(sa[start:lo])             # 출현 위치

print(search(s, sa, 'ana'), search(s, sa, 'nan'), search(s, sa, 'xyz'))   # [1, 3] [2] []

접미사 배열은 접미사 문자열 자체가 아니라 각 접미사가 시작하는 인덱스만 저장합니다(결과 배열은 인덱스 n개). 위 코드는 접미사를 키로 삼아 인덱스를 정렬하는 가장 단순한 구성법으로, "banana"에서 [5, 3, 1, 0, 4, 2]가 나옵니다. 시각화의 구성 탭이 보여 주는 순서와 같습니다. 검색은 정렬된 접미사에 대한 이진 탐색을 두 번 합니다. 첫 번째는 앞 len(p)글자가 패턴 이상인 첫 접미사를, 두 번째는 패턴보다 큰 첫 접미사를 찾아, 그 사이가 패턴으로 시작하는 접미사의 구간입니다. "ana"는 구간 [1, 3)에 접미사 두 개(인덱스 3과 1)가 있어 위치 [1, 3]이 나옵니다. 이 단순한 구성은 접미사 비교에 최대 O(n)이 걸려 전체가 O(n^2 log n)에 이를 수 있고, 정렬 키로 접미사 문자열을 임시로 만들어 메모리도 O(n^2) 쓰므로 학습용입니다. 실제로는 O(n log n)이나 O(n)에 구성하는 알고리즘을 씁니다.

Python — Kasai 알고리즘으로 LCP 배열 구하기

def kasai(s, sa):
    n = len(s)
    rank = [0] * n
    for i, p in enumerate(sa): rank[p] = i      # 접미사 p의 사전순 순위
    lcp = [0] * n                         # lcp[i] = sa[i-1]과 sa[i]의 공통 접두사 길이
    h = 0
    for i in range(n):
        if rank[i] > 0:
            j = sa[rank[i] - 1]                # 사전순으로 바로 앞 접미사
            while i + h < n and j + h < n and s[i + h] == s[j + h]:
                h += 1
            lcp[rank[i]] = h
            if h > 0: h -= 1                # 다음 접미사는 최소 h-1은 같다
        else:
            h = 0
    return lcp

lcp = kasai(s, sa)
print(lcp)                             # [0, 1, 3, 0, 0, 2]

LCP 배열의 lcp[i]는 사전순으로 이웃한 접미사 sa[i - 1]과 sa[i]가 앞에서부터 몇 글자까지 같은지를 나타냅니다. "banana"에서는 [0, 1, 3, 0, 0, 2]로, 시각화의 LCP 탭에서 이웃한 쌍을 위에서부터 비교한 값과 같습니다. Kasai 알고리즘은 문자열 순서대로(i = 0, 1, 2, ...) 접미사를 보면서, 접미사 i와 사전순으로 바로 앞 접미사의 공통 접두사가 h(> 0)글자였다면 접미사 i + 1과 그 사전순 앞 접미사는 최소 h - 1글자를 공유한다는 성질로 h를 거의 줄이지 않고 이어 갑니다. h는 한 번에 최대 1씩 줄고 n을 넘지 못하므로 전체 증가 횟수가 2n 이하여서 O(n)입니다. 순위 배열 rank(접미사 p가 사전순 몇 번째인지)가 필요해서 접미사 배열을 먼저 만든 뒤에 호출합니다.

Python — 가장 긴 반복 부분 문자열과 서로 다른 부분 문자열 수

def analyze(s):
    sa = build_sa(s)
    lcp = kasai(s, sa)
    k = max(range(len(s)), key=lambda i: lcp[i])
    longest = s[sa[k]:sa[k] + lcp[k]]                  # LCP의 최댓값이 가리키는 접두사
    distinct = len(s) * (len(s) + 1) // 2 - sum(lcp)    # 전체 접두사 수 - LCP 합
    return longest, distinct

for w in ['banana', 'mississippi', 'abracadabra']:
    print(w, analyze(w))
# banana ('ana', 15)
# mississippi ('issi', 53)
# abracadabra ('abra', 54)

LCP의 최댓값은 두 번 이상 나타나는 가장 긴 부분 문자열의 길이입니다. 그 값을 가진 이웃 쌍이 공통으로 가진 접두사가 바로 그 문자열입니다. "banana"에서 LCP의 최댓값은 3이고 문자열은 "ana"입니다. 서로 다른 부분 문자열의 개수는 모든 접미사의 접두사 수 n(n + 1) / 2에서 이웃 접미사끼리 겹치는 접두사 수 LCP의 합을 뺀 값입니다. "banana"는 21 - 6 = 15개입니다. 모든 부분 문자열을 직접 모아 세어도 mississippi는 53개입니다. 접미사 배열과 LCP 배열이 주어지면 이 두 값은 한 번 훑어 선형 시간에 계산되어서, 접미사 배열이 단순한 검색 자료구조를 넘어 문자열 통계에도 쓰이는 이유가 됩니다.
