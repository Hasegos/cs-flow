Java — 투 포인터 (정렬 배열에서 두 수의 합)

/* ── 양 끝에서 시작해 서로를 향해 좁혀 들어감 ──────────────── */
public int[] twoSumSorted(int[] arr, int target) {
    int left = 0, right = arr.length - 1;

    while (left < right) {
        int sum = arr[left] + arr[right];
        if (sum == target) {
            return new int[]{left, right};      // 발견
        } else if (sum < target) {
            left++;                          // 더 큰 값이 필요 → 왼쪽을 오른쪽으로
        } else {
            right--;                         // 더 작은 값이 필요 → 오른쪽을 왼쪽으로
        }
    }
    return new int[]{-1, -1};                // 못 찾음
}

left와 right는 각자 최대 배열 길이만큼만 움직이고 절대 서로를 지나치거나 되돌아가지 않으므로, while문 전체 반복 횟수는 O(n)입니다.
모든 (i, j) 쌍을 확인하는 이중 반복문(O(n²))과 달리, "정렬되어 있다"는 사실 하나로 절반 이상의 쌍을 아예 확인하지 않고 건너뜁니다.

Java — 슬라이딩 윈도우 (합이 target 이상인 최소 길이 구간)

/* ── 오른쪽으로 늘리고, 조건을 만족하면 왼쪽부터 줄여봄 ────── */
public int minSubArrayLen(int[] arr, int target) {
    int left = 0, sum = 0, minLen = Integer.MAX_VALUE;

    for (int right = 0; right < arr.length; right++) {
        sum += arr[right];                   // 오른쪽으로 창을 늘림

        while (sum >= target) {              // 조건을 만족하는 동안 계속 줄여봄
            minLen = Math.min(minLen, right - left + 1);
            sum -= arr[left];
            left++;                          // 왼쪽을 줄임
        }
    }
    return minLen == Integer.MAX_VALUE ? 0 : minLen;
}

right는 바깥 for문에서 n번, left는 안쪽 while문에서 전체 실행에 걸쳐 최대 n번만 움직입니다 — 겹쳐 있는 반복문처럼 보여도 합치면 O(n) + O(n) = O(n)입니다.
while문 안에서 조건을 만족하는 "동안 계속" 줄이는 것이 핵심입니다 — 한 번만 줄이고 멈추면 더 짧은 구간을 놓칠 수 있습니다.

Java — 슬라이딩 윈도우 (크기 고정, 최대 합)

/* ── 창 크기가 항상 k로 고정된 경우 ────────────────────────── */
public int maxSumFixedWindow(int[] arr, int k) {
    int windowSum = 0;
    for (int i = 0; i < k; i++) windowSum += arr[i];   // 첫 창의 합을 미리 계산

    int maxSum = windowSum;
    for (int right = k; right < arr.length; right++) {
        windowSum += arr[right] - arr[right - k];   // 새로 들어온 값 더하고, 빠진 값 빼기
        maxSum = Math.max(maxSum, windowSum);
    }
    return maxSum;
}

크기가 고정된 창은 매번 k개를 다시 더하지 않고, arr[right] - arr[right - k]처럼 "새로 들어온 값만 더하고 빠진 값만 빼는" 방식으로 O(1)에 갱신합니다.
이렇게 하면 전체 시간복잡도가 O(n·k)가 아니라 O(n)이 됩니다 — 이 시각화의 가변 크기 윈도우와 함께, 슬라이딩 윈도우의 두 가지 대표 유형(고정 크기 / 가변 크기)을 이룹니다.
