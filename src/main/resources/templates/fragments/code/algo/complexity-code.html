Java — O(1) 상수 시간

/* ── 입력 크기가 아무리 커져도 항상 딱 한 번만 연산 ────────── */
public int getFirst(int[] arr) {
    return arr[0];   // 배열 길이와 무관하게 즉시 반환
}

배열이 10개짜리든 1,000,000개짜리든, 인덱스로 값 하나를 꺼내는 데 걸리는 연산 횟수는 항상 1번입니다.
입력 크기 n과 실행 시간이 아예 무관하기 때문에 O(1)이라고 표기합니다.

Java — O(n) 선형 시간

/* ── 배열을 한 번 훑으며 최댓값을 찾음 ─────────────────────── */
public int findMax(int[] arr) {
    int max = arr[0];
    for (int i = 1; i < arr.length; i++) {   // arr.length번 반복
        if (arr[i] > max) max = arr[i];
    }
    return max;
}

반복문이 arr.length번, 즉 입력 크기 n만큼 정확히 한 번씩 실행됩니다.
n이 2배로 늘면 연산 횟수도 2배로 늘어나는, 입력 크기에 정비례하는 O(n) 시간복잡도입니다.

Java — O(n²) 이차 시간

/* ── 이중 for문: 모든 쌍(i, j)을 서로 비교 ─────────────────── */
public boolean hasDuplicate(int[] arr) {
    for (int i = 0; i < arr.length; i++) {
        for (int j = i + 1; j < arr.length; j++) {   // i마다 arr.length번 가까이 반복
            if (arr[i] == arr[j]) return true;
        }
    }
    return false;
}

바깥 반복문이 n번 돌 때마다 안쪽 반복문도 매번 n번 가까이 돌기 때문에, 전체 연산 횟수는 대략 n × n번입니다.
n이 2배로 늘면 연산 횟수는 4배로 늘어나는 O(n²) 시간복잡도이며, ds-09(정렬 알고리즘)의 버블 정렬이 대표적인 예입니다.
O(log n)은 다음 토픽(이진 탐색)에서, O(2ⁿ)은 ds-10(동적 프로그래밍)의 완전 탐색에서 이미 확인했습니다.
