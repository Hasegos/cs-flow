Python — 실패 함수와 KMP 검색

def prefix_function(p):
    pi = [0] * len(p)
    j = 0
    for i in range(1, len(p)):
        while j > 0 and p[i] != p[j]:
            j = pi[j - 1]                    # 더 짧은 접두사로 되돌린다
        if p[i] == p[j]:
            j += 1
        pi[i] = j
    return pi

def kmp_search(t, p):
    pi = prefix_function(p)
    found = []
    j = 0
    for i, c in enumerate(t):               # i는 한 번도 뒤로 가지 않는다
        while j > 0 and c != p[j]:
            j = pi[j - 1]                    # 패턴만 민다
        if c == p[j]:
            j += 1
        if j == len(p):
            found.append(i - j + 1)       # 일치 시작 위치
            j = pi[j - 1]                    # 겹치는 일치도 찾는다
    return found

print(prefix_function('ABABC'))                    # [0, 0, 1, 2, 0]
print(kmp_search('ABABABCABABC', 'ABABC'))       # [2, 7]

실패 함수 pi[i]는 패턴의 앞 i+1글자에서 자기 자신을 제외하고 접두사이면서 접미사이기도 한 가장 긴 문자열의 길이입니다. ABABC에서는 ABAB의 끝 AB가 앞 AB와 같아 pi[3] = 2이고, 나머지는 겹치는 부분이 없거나 1입니다. 패턴을 자기 자신 위에 겹쳐 밀며 구하므로 O(m)입니다. 검색에서는 텍스트 위치 i와 패턴 위치 j를 함께 움직입니다. 글자가 같으면 j를 늘리고, 다르면 i는 그대로 두고 j만 pi[j - 1]로 줄입니다. 이미 맞춘 ABAB 중 앞 AB는 다시 비교하지 않아도 되기 때문입니다. j가 패턴 길이에 닿으면 일치 하나를 찾은 것이고, 이어서 j를 pi[j - 1]로 줄여 겹치는 일치도 찾습니다. 위 텍스트에서는 위치 2와 7에서 일치합니다. 시각화의 실패 함수 만들기 탭과 KMP 검색 탭이 보여 주는 과정과 같습니다.

Python — 단순 검색과 비교 횟수

def naive_count(t, p):
    cmp = 0
    for s in range(len(t) - len(p) + 1):
        for k in range(len(p)):
            cmp += 1
            if t[s + k] != p[k]:
                break
    return cmp

def kmp_count(t, p):
    pi = prefix_function(p)
    cmp = 0
    j = 0
    for c in t:
        while j > 0 and c != p[j]:
            cmp += 1
            j = pi[j - 1]
        cmp += 1
        if c == p[j]:
            j += 1
        if j == len(p):
            j = pi[j - 1]
    return cmp

print(naive_count('ABABABCABABC', 'ABABC'), kmp_count('ABABABCABABC', 'ABABC'))   # 22 13
t = 'A' * 100 + 'B'
p = 'A' * 20 + 'B'
print(naive_count(t, p), kmp_count(t, p))              # 1701 181

단순 검색은 모든 시작 위치에서 패턴의 처음부터 비교하고, 불일치가 나면 한 칸 밀어 처음부터 다시 비교합니다. 위의 짧은 예에서는 글자 비교가 22번 대 13번으로 KMP가 적지만 차이가 크지 않습니다. 같은 글자가 길게 반복되는 입력에서는 차이가 커집니다. A가 100개 뒤에 B가 하나 있는 텍스트에서 A 20개와 B로 이루어진 패턴을 찾으면 단순 검색은 1701번, KMP는 181번 비교합니다. 단순 검색은 최악에 O(n × m)이고 KMP는 텍스트를 한 번만 훑어 O(n + m)이기 때문입니다.

Java — KMP 검색

static int[] prefixFunction(String p) {
    int[] pi = new int[p.length()];
    int j = 0;
    for (int i = 1; i < p.length(); i++) {
        while (j > 0 && p.charAt(i) != p.charAt(j)) j = pi[j - 1];
        if (p.charAt(i) == p.charAt(j)) j++;
        pi[i] = j;
    }
    return pi;
}

static List<Integer> search(String t, String p) {
    int[] pi = prefixFunction(p);
    List<Integer> res = new ArrayList<>();
    int j = 0;
    for (int i = 0; i < t.length(); i++) {
        while (j > 0 && t.charAt(i) != p.charAt(j)) j = pi[j - 1];
        if (t.charAt(i) == p.charAt(j)) j++;
        if (j == p.length()) {
            res.add(i - j + 1);
            j = pi[j - 1];
        }
    }
    return res;
}

// prefixFunction("ABABC") → [0, 0, 1, 2, 0]
// search("ABABABCABABC", "ABABC") → [2, 7]

자바 버전도 같은 구조입니다. 실패 함수를 한 번 만들어 두면 같은 패턴으로 여러 텍스트를 검색할 때 다시 계산하지 않아도 됩니다. 이 구현은 패턴이 빈 문자열이 아니라고 가정하므로, 실무에서는 빈 패턴을 먼저 걸러야 합니다. 자바 String.indexOf나 파이썬 str.find 같은 표준 함수로 단순한 검색은 해결됩니다. KMP는 알고리즘 교재의 표준 주제이고, 한 글자씩 들어오는 입력에서 j와 π 배열만으로 검색하거나 π 배열을 응용하는 문제에서 그 원리를 씁니다.
