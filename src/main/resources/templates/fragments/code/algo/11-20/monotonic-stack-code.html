Python — 다음 큰 원소

def next_greater(a):
    ans = [-1] * len(a)                       # 답이 없으면 -1
    st = []                                   # 아직 답을 못 찾은 원소의 인덱스
    for i, x in enumerate(a):
        while st and a[st[-1]] < x:         # 새 원소가 top보다 크면
            ans[st.pop()] = x                 # top의 답이 확정된다
        st.append(i)
    return ans

print(next_greater([2, 7, 3, 5, 4, 6, 8]))   # [7, 8, 5, 6, 6, 8, -1]

각 원소의 오른쪽에서 처음 나오는 더 큰 값을 구합니다. 원소마다 오른쪽을 끝까지 훑으면 O(n²)이지만, 스택에 아직 답을 찾지 못한 원소의 인덱스를 쌓아 두면 O(n)에 풉니다. 새 원소 x가 오면 스택 맨 위의 값이 x보다 작은 동안 계속 꺼내며 그 원소들의 답을 x로 확정하고, 마지막에 x의 인덱스를 넣습니다. 끝까지 스택에 남은 원소는 오른쪽에 더 큰 값이 없어 답이 -1입니다. 이 과정에서 스택의 값은 바닥에서 맨 위로 갈수록 줄어드는 단조 감소 순서가 유지됩니다. 새 원소가 큰 값이면 작은 값들을 모두 꺼내고 들어가기 때문입니다. 값 대신 인덱스를 쌓아야 값은 a[인덱스]로 읽고, 거리나 너비가 필요한 문제에서도 같은 스택을 쓸 수 있습니다. 시각화의 다음 큰 원소 탭이 보여 주는 과정과 같습니다.

Python — 히스토그램의 가장 큰 직사각형과 주가 스팬

def largest_rectangle(h):
    st, best = [], 0
    for i, cur in enumerate(h + [0]):          # 끝에 높이 0을 붙여 모두 꺼낸다
        while st and h[st[-1]] > cur:
            height = h[st.pop()]
            left = st[-1] + 1 if st else 0     # 왼쪽에서 처음 낮은 막대 다음
            best = max(best, height * (i - left))
        st.append(i)
    return best

print(largest_rectangle([2, 1, 5, 6, 2, 3]))             # 10

def stock_span(p):
    st, span = [], []
    for i, x in enumerate(p):
        while st and p[st[-1]] <= x:        # 오늘 이하인 날은 꺼낸다
            st.pop()
        span.append(i - st[-1] if st else i + 1)
        st.append(i)
    return span

print(stock_span([100, 80, 60, 70, 60, 75, 85]))   # [1, 1, 1, 2, 1, 4, 6]

같은 스택을 다른 문제에 적용한 예입니다. 히스토그램에서는 높이가 줄지 않는(같거나 늘어나는) 순서로 인덱스를 쌓고, 더 낮은 막대를 만나면 꺼내며 그 막대를 높이로 하는 직사각형의 넓이를 계산합니다. 왼쪽 경계는 꺼낸 뒤 스택에 남은 top의 다음 칸이고 오른쪽 경계는 현재 위치 직전입니다. 막대 높이 [2, 1, 5, 6, 2, 3]에서는 높이 5, 너비 2로 만든 넓이 10이 가장 큽니다. 주가 스팬은 오늘 가격 이하인 날들을 스택에서 꺼내고, 남은 top과의 거리를 스팬으로 합니다. 날마다 한 번 넣고 최대 한 번 꺼내므로 모두 O(n)입니다. 같은 값을 어떻게 다룰지(<로 비교할지 <=로 비교할지)에 따라 결과가 달라지므로 문제가 요구하는 조건을 확인해야 합니다. 시각화의 히스토그램 직사각형 탭과 주가 스팬 탭이 보여 주는 과정과 같습니다.

Java — Deque로 다음 큰 원소

static int[] nextGreater(int[] a) {
    int[] ans = new int[a.length];
    Arrays.fill(ans, -1);
    Deque<Integer> st = new ArrayDeque<>();       // 스택으로 쓰는 Deque
    for (int i = 0; i < a.length; i++) {
        while (!st.isEmpty() && a[st.peek()] < a[i]) {
            ans[st.pop()] = a[i];
        }
        st.push(i);
    }
    return ans;
}

// nextGreater(new int[]{2, 7, 3, 5, 4, 6, 8}) → [7, 8, 5, 6, 6, 8, -1]

자바에서는 오래된 Stack 클래스보다 Deque 인터페이스의 구현체인 ArrayDeque를 스택으로 쓰는 것이 권장됩니다. Stack의 Javadoc은 Deque와 그 구현체가 더 완전하고 일관된 후입선출 연산 집합을 제공하므로 Stack 대신 쓰라고 안내합니다. push와 pop은 맨 앞에서, peek는 맨 앞 값을 읽는 연산이라 모두 스택의 top과 같습니다. 결과는 파이썬과 같은 [7, 8, 5, 6, 6, 8, -1]입니다. push와 pop은 보통 O(1)이고 원소마다 한 번씩만 넣고 꺼내므로 전체 시간은 O(n)입니다.
