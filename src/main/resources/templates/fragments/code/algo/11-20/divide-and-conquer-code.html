Python — 병합 정렬

count = [0]                                       # 비교 횟수

def merge_sort(a):
    if len(a) <= 1:                              # 기저 사례: 이미 정렬됨
        return a
    mid = len(a) // 2
    left = merge_sort(a[:mid])                    # 분할 + 정복
    right = merge_sort(a[mid:])
    return merge(left, right)                    # 결합

def merge(left, right):
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        count[0] += 1
        if left[i] <= right[j]:
            out.append(left[i])
            i += 1
        else:
            out.append(right[j])
            j += 1
    return out + left[i:] + right[j:]          # 남은 조각을 이어 붙인다

print(merge_sort([38, 27, 43, 3, 9, 82, 10, 5]), count[0])
# [3, 5, 9, 10, 27, 38, 43, 82] 17

분할정복은 세 단계입니다. 문제를 더 작은 같은 문제로 나누고(분할), 각 부분을 재귀로 풀고(정복), 부분의 답을 합쳐 전체의 답을 만듭니다(결합). 병합 정렬에서 분할은 배열을 절반으로 가르는 일이고, 정복은 재귀 호출이며, 결합이 정렬된 두 조각을 하나로 합치는 merge 함수입니다. 길이가 1 이하인 조각은 이미 정렬된 상태라 재귀를 멈추는 기저 사례가 됩니다. merge는 두 조각의 맨 앞 원소를 비교해 작은 쪽을 꺼내므로 두 조각 길이의 합만큼의 시간이 듭니다. 시각화의 8개 원소 배열에서는 합치기 3단계에 비교가 4번, 6번, 7번 들어 모두 17번이고, 전체 시간은 O(n log n)입니다. 합치기에 임시 배열이 필요해서 추가 공간은 O(n)입니다. 같은 값이 있을 때 left[i] <= right[j]처럼 왼쪽을 먼저 꺼내면 원래 순서가 유지되는 안정 정렬이 됩니다. 시각화의 병합 정렬 탭이 보여 주는 과정과 같습니다.

Python — 분할정복 거듭제곱

def power(x, n):
    if n == 0:                                    # 기저 사례
        return 1
    half = power(x, n // 2)                    # 지수를 절반으로
    return half * half * x if n % 2 else half * half

print(power(2, 13), power(3, 5), power(2, 0))   # 8192 243 1

def power_iter(x, n):                           # 같은 아이디어를 반복문으로
    result = 1
    while n:
        if n & 1:
            result *= x
        x *= x
        n >>= 1
    return result

print(power_iter(2, 13))                  # 8192

x^n을 x를 n번 곱해서 구하면 곱셈이 n - 1번 필요하지만, x^n = x^⌊n/2⌋ × x^⌊n/2⌋로 지수를 절반씩 줄이면 호출이 log n 단계만 쌓입니다. n이 홀수이면 x를 한 번 더 곱합니다. 2^13은 호출이 13, 6, 3, 1, 0의 다섯 단계로 쌓이고 곱셈을 7번 해서 8192가 됩니다(단순하게 곱하면 12번). 부분 문제가 하나뿐이라 결합 비용이 상수이고 점화식이 T(n) = T(n/2) + O(1)이 되어 O(log n)입니다. 아래의 반복문 버전은 같은 아이디어를 지수의 비트를 아래부터 읽는 방식으로 옮긴 것이고, 재귀 깊이 없이 추가 변수 O(1)개로 계산합니다. 시각화의 거듭제곱 탭이 보여 주는 호출 쌓임과 같습니다.

Java — 병합 정렬

static int[] mergeSort(int[] a) {
    if (a.length <= 1) return a;
    int mid = a.length / 2;
    int[] left = mergeSort(Arrays.copyOfRange(a, 0, mid));
    int[] right = mergeSort(Arrays.copyOfRange(a, mid, a.length));
    int[] out = new int[a.length];
    int i = 0, j = 0, k = 0;
    while (i < left.length && j < right.length) {
        out[k++] = left[i] <= right[j] ? left[i++] : right[j++];
    }
    while (i < left.length) out[k++] = left[i++];
    while (j < right.length) out[k++] = right[j++];
    return out;
}

// mergeSort(new int[]{38, 27, 43, 3, 9, 82, 10, 5}) → [3, 5, 9, 10, 27, 38, 43, 82]

자바 버전도 같은 구조입니다. 배열을 절반으로 복사해 재귀로 정렬한 뒤 앞에서부터 비교하며 합치고, 한쪽이 먼저 끝나면 남은 쪽을 그대로 이어 붙입니다. 비교 횟수는 파이썬 예와 같이 17번입니다. 분할정복이 항상 빠른 것은 아닙니다. 조각을 나누고 합치는 비용이 있고, 부분 문제가 서로 겹치면 같은 문제를 여러 번 푸는 낭비가 생깁니다. 그런 경우에는 결과를 저장해 두는 동적 계획법이 알맞습니다.
