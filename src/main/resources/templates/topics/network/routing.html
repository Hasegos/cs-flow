라우팅

태그

라우팅은 패킷이 출발지에서 목적지까지 최적의 경로를 찾아 이동하는 과정입니다. 라우터는 라우팅 테이블을 참조해 다음 홉(Next Hop)을 결정하며, RIP·OSPF·BGP 같은 라우팅 프로토콜이 이 테이블을 동적으로 갱신합니다.

핵심 개념

정적 vs 동적 라우팅

정적 라우팅은 관리자가 수동으로 경로를 설정합니다. 오버헤드가 없고 예측 가능하지만 네트워크 변화에 자동 대응이 불가능합니다. 동적 라우팅은 프로토콜이 자동으로 경로를 학습하고 갱신합니다. 장애 발생 시 대체 경로를 자동으로 찾습니다.

핵심 개념

RIP (거리 벡터)

Routing Information Protocol. 목적지까지의 홉(Hop) 수를 메트릭으로 사용합니다. 주기적으로(30초) 인접 라우터에 전체 라우팅 테이블을 브로드캐스트합니다. 최대 홉 수 15로 소규모 네트워크에 적합합니다. 수렴 속도가 느리고 라우팅 루프 문제가 있습니다.

핵심 개념

OSPF (링크 상태)

Open Shortest Path First. 대역폭 기반 비용(Cost)을 메트릭으로 사용합니다. 각 라우터가 전체 네트워크 토폴로지를 파악하고 다익스트라 알고리즘으로 최단 경로를 계산합니다. 변화 발생 시에만 LSA를 전파해 빠른 수렴과 확장성을 제공합니다.

핵심 개념

BGP (경계 게이트웨이)

Border Gateway Protocol. 인터넷의 AS(자율 시스템) 간 라우팅을 담당합니다. 경로 속성(AS-PATH, NEXT-HOP, MED 등)을 기반으로 정책적 라우팅을 수행합니다. 인터넷의 핵심 라우팅 프로토콜로 전 세계 AS 간 경로 정보를 교환합니다.

핵심 개념

라우팅 테이블

목적지 네트워크, 서브넷 마스크, 게이트웨이(Next Hop), 인터페이스, 메트릭으로 구성됩니다. 패킷 수신 시 목적지 IP와 가장 길게 일치하는 항목(Longest Prefix Match)을 선택합니다. 기본 경로(0.0.0.0/0)는 일치 항목이 없을 때 사용하는 최후의 수단입니다.

핵심 개념

AS와 IGP/EGP

AS(Autonomous System)는 단일 관리 체계 아래 있는 라우터 집합입니다. IGP(Interior Gateway Protocol)는 AS 내부 라우팅으로 RIP·OSPF·EIGRP가 있습니다. EGP(Exterior Gateway Protocol)는 AS 간 라우팅으로 BGP가 사실상 유일한 표준입니다.

다익스트라 알고리즘 (OSPF) — OSPF는 각 라우터가 링크 상태 데이터베이스(LSDB)를 기반으로 다익스트라 SPF 알고리즘을 실행해 최단 경로 트리를 계산합니다. 비용(Cost) = 10^8 / 대역폭(bps)으로, 100Mbps 링크의 비용은 1입니다.
라우팅 루프와 분할 지평선 — RIP에서 A→B→C 경로 장애 시 B와 C가 서로를 통해 A로 갈 수 있다고 잘못 학습하는 루프가 발생할 수 있습니다. 분할 지평선(Split Horizon)은 경로를 배운 방향으로 다시 광고하지 않아 이를 방지합니다.
ECMP (Equal-Cost Multi-Path) — 같은 비용의 경로가 여러 개일 때 트래픽을 분산합니다. OSPF와 EIGRP 모두 지원하며, 라운드 로빈이나 해시 기반으로 분산합니다. 링크 활용도를 높이고 장애 내성을 강화합니다.
SDN (소프트웨어 정의 네트워킹) — 제어 평면(Control Plane)을 데이터 평면(Data Plane)에서 분리해 중앙에서 라우팅을 제어합니다. OpenFlow 프로토콜로 스위치·라우터를 프로그래밍합니다. 클라우드 데이터센터에서 많이 사용됩니다.
