CDN

태그

CDN(Content Delivery Network)은 전 세계 여러 위치에 분산된 엣지 서버를 통해 사용자에게 가장 가까운 서버에서 콘텐츠를 전달하는 네트워크입니다. 정적 파일, 이미지, 동영상을 캐싱해 응답 속도를 높이고 오리진 서버의 부하를 줄입니다.

핵심 개념

엣지 서버와 PoP

PoP(Point of Presence)는 CDN이 전 세계에 배치한 데이터 센터입니다. 각 PoP에는 엣지 서버가 있어 오리진 서버에서 콘텐츠를 캐싱합니다. 사용자는 DNS를 통해 가장 가까운 PoP로 라우팅됩니다. Cloudflare는 300개 이상의 PoP를 운영합니다.

핵심 개념

캐시 히트 / 미스

캐시 히트는 요청한 콘텐츠가 엣지 서버에 이미 있는 경우입니다. 응답이 빠르고 오리진 서버에 요청하지 않습니다. 캐시 미스는 콘텐츠가 없거나 만료된 경우로, 엣지 서버가 오리진에서 콘텐츠를 가져와 캐싱합니다. 히트율(Hit Rate)이 높을수록 CDN 효율이 좋습니다.

핵심 개념

Cache-Control 헤더

TTL(Time To Live)로 캐시 유효 기간을 설정합니다. max-age=31536000은 1년간 캐싱을 의미합니다. immutable은 콘텐츠가 변경되지 않음을 알려 재검증을 생략합니다. no-cache는 매번 오리진에 재검증 요청을 보냅니다. 정적 파일은 긴 TTL, HTML은 짧은 TTL을 권장합니다.

핵심 개념

캐시 무효화

콘텐츠 변경 시 기존 캐시를 무효화합니다. URL에 해시를 포함하는 캐시 버스팅(app.a1b2c3.js)이 가장 효율적입니다. CDN API로 특정 파일이나 경로를 강제 퍼지(purge)할 수 있습니다. Cloudflare는 캐시 퍼지 API를 제공하며, 배포 시 자동으로 퍼지합니다.

핵심 개념

동적 콘텐츠 가속

CDN은 정적 파일만 캐싱하지 않습니다. TCP 연결 재사용, TLS 종료 최적화, HTTP/2·3 지원으로 동적 API 응답도 가속합니다. Cloudflare Argo는 최적화된 경로를 통해 동적 요청의 네트워크 지연을 줄입니다. 오리진 서버와 CDN 간 연결을 상시 유지합니다.

핵심 개념

보안 기능

CDN은 DDoS 방어, WAF(Web Application Firewall), Bot 관리를 제공합니다. 오리진 IP를 숨겨 직접 공격을 차단합니다. Cloudflare는 1.1.1.1 DNS를 통해 글로벌 트래픽을 분석하고 악성 IP를 차단합니다. SSL/TLS 인증서를 자동으로 발급하고 갱신합니다.

Anycast 라우팅 — CDN은 동일한 IP 주소를 여러 PoP가 공유합니다. 사용자 요청은 BGP 라우팅을 통해 자동으로 가장 가까운 PoP로 전달됩니다. Cloudflare의 IP 주소에 요청하면 전 세계 어디서든 가장 가까운 데이터 센터가 응답합니다.
CDN과 Spring Boot — Cloudflare를 오리진 앞에 두면 정적 리소스는 엣지에서 캐싱하고, API 요청은 오리진으로 전달합니다. Spring의 Cache-Control 헤더 설정이 CDN 캐싱 동작을 결정합니다. csflow.kr이 이 구조로 동작하고 있습니다.
Stale-While-Revalidate — 캐시가 만료되면 즉시 삭제하는 대신, 만료된 콘텐츠를 일시적으로 제공하면서 백그라운드에서 새 콘텐츠를 가져옵니다. 사용자는 캐시 미스 없이 응답을 받고, 잠시 후 최신 콘텐츠로 교체됩니다. 응답 속도와 최신성을 동시에 확보합니다.
