KMP 문자열 검색

태그

KMP 알고리즘은 긴 텍스트에서 패턴이 나타나는 모든 위치를 찾는 문자열 검색 알고리즘입니다. 이름은 만든 사람인 크누스(Knuth), 모리스(Morris), 프랫(Pratt)의 첫 글자에서 왔습니다. 핵심은 이미 맞춰 본 글자를 다시 비교하지 않는 것이고, 그 덕분에 텍스트 길이 n, 패턴 길이 m에 대해 O(n + m) 시간에 검색합니다.

단순한 방법은 텍스트의 모든 위치에서 패턴을 처음부터 비교하다가 불일치가 나면 한 칸 밀고 처음부터 다시 비교합니다. 앞에서 맞춘 글자 정보를 버리기 때문에 최악에는 O(n × m)이 걸립니다. KMP는 패턴을 미리 분석해 "불일치가 났을 때 패턴을 어디까지 밀어도 안전한가"를 실패 함수라는 표로 만들어 두고, 텍스트 위치를 뒤로 되돌리지 않은 채 패턴만 이동합니다. 이 토픽에서는 실패 함수를 만드는 과정, 그것을 쓰는 검색 과정, 단순 검색과의 비교를 봅니다.

핵심 개념

문자열 검색

텍스트 안에서 패턴과 같은 부분 문자열의 시작 위치를 찾는 문제입니다. 모든 일치 위치를 구하거나 처음 하나만 구하기도 합니다.

핵심 개념

접두사와 접미사

문자열의 앞쪽 일부가 접두사, 뒤쪽 일부가 접미사입니다. ABAB의 접두사 AB와 접미사 AB는 같고, 이 겹침이 KMP가 재사용하는 정보입니다.

핵심 개념

실패 함수 π

π[i]는 패턴의 앞 i+1글자에서, 자기 자신을 제외하고 접두사이면서 접미사이기도 한 가장 긴 문자열의 길이입니다. 접두사 함수라고도 부릅니다.

핵심 개념

두 포인터 i와 j

i는 텍스트 위치, j는 지금까지 맞춘 패턴 글자 수입니다. 글자가 같으면 둘 다 전진하고, 다르면 j가 0보다 클 때 i는 두고 j만 π[j-1]로 줄이며 j가 0이면 i가 한 칸 전진합니다.

핵심 개념

텍스트를 되돌리지 않음

텍스트 위치 i는 한 번도 뒤로 가지 않습니다. 이미 맞춘 글자의 정보는 j에 담겨 있어서 같은 글자를 처음부터 다시 확인하지 않습니다.

핵심 개념

겹치는 일치

패턴을 모두 맞추면 j를 π[m-1]로 줄여 이어갑니다. 그러면 AAA 안의 AA처럼 서로 겹치는 일치도 놓치지 않고 찾습니다.

시간은 O(n + m)입니다 — 실패 함수를 만드는 데 O(m), 검색에 O(n)입니다. i는 앞으로만 가고 j는 늘어난 만큼만 줄어들기 때문에 총 이동 횟수가 선형으로 묶입니다.
추가 공간은 O(m)입니다 — 패턴 길이만큼의 π 배열 하나가 필요합니다(일치 위치 출력은 제외). 텍스트는 읽기만 하므로 추가 공간이 없습니다.
같은 패턴은 한 번만 분석합니다 — π 배열을 한 번 만들어 두면 같은 패턴으로 여러 텍스트를 검색할 때 다시 계산하지 않아도 됩니다.
입력 순서대로 읽을 수 있습니다 — 텍스트를 되돌리지 않으므로 한 글자씩 들어오는 스트림에서도 j 하나와 미리 만든 π 배열만 있으면 텍스트를 저장하지 않고 검색할 수 있습니다.
이 시각화에서 확인할 것 — "실패 함수 만들기" 탭에서 패턴을 자기 자신 위에 밀며 π가 채워지는 모습을, "KMP 검색" 탭에서 불일치 때 i를 두고 j만 줄이는 모습을, "단순 검색과 비교" 탭에서 같은 입력의 비교 횟수 차이를 STEP으로 확인하세요.

KMP의 배경

KMP 알고리즘은 1977년 크누스, 모리스, 프랫이 "Fast pattern matching in strings"라는 논문으로 함께 발표했고, SIAM Journal on Computing에 실렸습니다. 같은 해 보이어(Boyer)와 무어(Moore)도 평균적으로 아주 빠른 다른 검색 알고리즘을 발표했습니다. KMP의 실패 함수 아이디어는 1975년 아호-코라식(Aho-Corasick) 알고리즘이 여러 패턴을 한꺼번에 찾도록 확장하는 데 쓰였고, KMP는 그보다 앞선 1974년 기술 보고서로 먼저 알려졌습니다.

숫자로 확인하기

실패 함수 — 패턴 ABABC의 π는 [0, 0, 1, 2, 0]입니다. ABAB의 끝 AB가 앞 AB와 같아 π[3] = 2이고, C에서는 겹치는 부분이 사라져 π[4] = 0입니다. 같은 글자만 이어지는 AAAA는 [0, 1, 2, 3]입니다.
검색 — 텍스트 ABABABCABABC에서 ABABC를 찾으면 위치 2와 7에서 일치합니다. 텍스트 위치 4의 A가 패턴의 C와 달라도 j를 4에서 π[3] = 2로 줄이고 i는 그대로 두어, 이미 맞춘 AB는 다시 비교하지 않고 이어서 맞춥니다.
비교 횟수 — 이 입력에서 글자 비교는 단순 검색이 22번, KMP가 13번입니다. 입력이 짧아 차이가 작습니다.
반복이 많은 입력 — A가 100개 뒤에 B가 하나 있는 텍스트에서 A 20개와 B로 이루어진 패턴을 찾으면 단순 검색은 1701번, KMP는 181번 비교합니다.
문자열의 주기 — ABABAB의 π는 [0, 0, 1, 2, 3, 4]이고 길이 6에서 마지막 π 값 4를 뺀 2가 가장 짧은 반복 단위의 길이이며, 6이 2로 나누어떨어지므로 AB가 세 번 반복된 문자열입니다.
코드 확인 — 파이썬과 자바 구현이 같은 π와 일치 위치 [2, 7]을 돌려줍니다.

자주 하는 오해

접두사와 접미사에 자기 자신도 포함한다 — 자기 자신은 제외합니다. 포함하면 모든 π[i]가 i+1이 되어 아무 정보도 주지 못합니다.
텍스트 글자를 한 번만 비교한다 — 텍스트 위치 i는 되돌아가지 않지만, 한 글자가 불일치 때문에 j가 줄어든 패턴 글자와 여러 번 비교될 수 있습니다. 전체 비교 횟수가 선형으로 묶일 뿐입니다.
실패하면 j를 0으로 되돌린다 — 그러면 단순 검색과 다를 바 없습니다. 불일치가 나면 π[j-1]로 줄여 접두사의 일부를 그대로 이어 갑니다.
KMP가 언제나 가장 빠르다 — KMP는 최악에도 선형을 보장하는 점이 강점입니다. 평균적으로는 글자를 건너뛰는 보이어-무어 같은 방법이 더 빠른 경우가 많습니다.
일치를 찾으면 j를 0으로 되돌려 다시 시작한다 — 그러면 서로 겹치는 일치를 놓칩니다. j를 π[m-1]로 줄여 이어야 합니다. 예를 들어 AAAA에서 AA를 찾을 때 위치 0, 1, 2 세 곳이 모두 나옵니다.

면접에서 이렇게 물어요

면접 질문

KMP 알고리즘의 핵심 아이디어는?

불일치가 났을 때 이미 맞춘 글자의 정보를 실패 함수로 재사용해, 텍스트 위치를 되돌리지 않고 패턴만 이동하는 것입니다. 그래서 같은 글자를 처음부터 다시 비교하지 않습니다.

면접 질문

실패 함수(π 배열)는 무엇인가요?

π[i]는 패턴의 앞 i+1글자에서 접두사이면서 접미사인 가장 긴 (자기 자신을 제외한) 문자열의 길이입니다. 불일치 때 패턴을 얼마나 되돌려 이어 비교할 수 있는지를 알려 줍니다.

면접 질문

시간 복잡도가 O(n + m)인 이유는?

텍스트 위치 i는 앞으로만 가고, j는 한 칸씩 늘어나며 줄어드는 양이 늘어난 양을 넘을 수 없습니다. 그래서 검색의 총 이동이 O(n)이고, 같은 논리로 실패 함수 계산은 O(m)입니다.

면접 질문

문자열이 어떤 단위의 반복인지 알아내려면?

길이 n인 문자열의 마지막 π 값을 뺀 n − π[n-1]이 후보 단위의 길이이고, n이 그 값으로 나누어떨어지고 그 값이 n보다 작으면 그 단위가 반복된 문자열입니다.

활용 분야와 확장

다중 패턴 검색 — 아호-코라식 알고리즘은 KMP의 실패 함수 아이디어를 패턴 여러 개를 담은 트라이로 확장해, 사전의 모든 단어를 텍스트에서 한 번에 찾습니다.
스트림 처리 — 텍스트를 되돌리지 않고 j와 π 배열로 상태를 유지하므로, 한 글자씩 들어오는 입력에서 패턴이 나타나는 순간을 찾는 데 알맞습니다.
문자열 문제 — 반복 단위 찾기, 접두사와 접미사가 겹치는 가장 긴 길이 구하기 같은 문제에서 π 배열이 그대로 쓰입니다.

함께 보면 좋은 토픽

트라이 — 여러 문자열을 한 번에 다루는 자료구조와 아호-코라식의 바탕을 봅니다.
접미사 배열 — 접미사를 정렬해 부분 문자열을 검색하는 다른 방법을 봅니다.
투 포인터 — 두 위치를 함께 움직이는 기법을 봅니다.
시간 복잡도 — O(n × m)과 O(n + m)의 차이를 봅니다.
