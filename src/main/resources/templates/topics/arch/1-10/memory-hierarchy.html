메모리 계층 구조

태그

메모리 계층 구조(Memory Hierarchy)는 속도와 용량이 반비례하는 저장 장치들을 계층으로 배치한 구조입니다. CPU에 가까울수록 빠르고 비싸며 용량이 작고, 멀어질수록 느리지만 저렴하고 용량이 큽니다.

계층 1

레지스터 (Register)

CPU 내부에 위치한 가장 빠른 저장 공간입니다. 접근 시간 1ns 미만, 용량은 수십~수백 바이트 수준입니다.

계층 2

L1 / L2 / L3 캐시

CPU와 RAM 사이의 고속 버퍼입니다. L1은 수 KB, L2는 수백 KB, L3는 수 MB 규모이며 접근 시간은 1~40ns입니다.

계층 3

메인 메모리 (RAM)

프로그램 실행 시 데이터를 올려두는 주기억장치입니다. 수 GB~수십 GB 용량, 접근 시간 60~100ns입니다.

계층 4

보조 기억 장치 (SSD/HDD)

영구 저장 장치입니다. SSD는 수십~수백 μs, HDD는 수 ms 접근 시간이며 수백 GB~수 TB 용량을 제공합니다.

핵심 원리

지역성 원리

시간 지역성(최근 사용 데이터 재사용)과 공간 지역성(인접 주소 데이터 접근)을 이용해 상위 계층 적중률을 높입니다.

핵심 원리

계층 간 데이터 이동

상위 계층에 데이터가 없으면(Miss) 하위 계층에서 블록 단위로 가져옵니다. 히트율이 높을수록 전체 성능이 향상됩니다.

속도 vs 용량 트레이드오프 — 레지스터는 RAM보다 약 100배 빠르지만 용량은 수억 배 작습니다. 계층 구조는 이 간극을 효율적으로 메웁니다.
평균 접근 시간 — 히트율 h, 캐시 접근 시간 Tc, 메모리 접근 시간 Tm일 때: 평균 접근 시간 = h×Tc + (1-h)×Tm 로 계산합니다.
캐시 일관성 (Cache Coherence) — 멀티코어 환경에서 각 코어의 L1 캐시가 같은 메모리 주소에 대해 다른 값을 가지면 안 됩니다. MESI 프로토콜 등으로 해결합니다.
가상 메모리 — RAM이 부족할 때 SSD/HDD 일부를 RAM처럼 사용하는 기법입니다. 페이지 폴트 발생 시 디스크에서 페이지를 로드합니다.
비용 구조 — SRAM(캐시)은 DRAM(RAM)보다 셀당 단가가 수십 배 높습니다. 이 때문에 캐시는 소용량으로만 사용됩니다.
