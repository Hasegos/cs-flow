폰 노이만 구조

태그

폰 노이만 구조는 프로그램 내장 방식(Stored Program)을 기반으로 한 컴퓨터 설계 원칙입니다. 데이터와 명령어를 동일한 메모리에 저장하고, CPU가 순차적으로 명령어를 꺼내 실행하는 방식으로 현대 컴퓨터의 근간입니다.

핵심 구성

CPU

ALU(연산장치)와 CU(제어장치)로 구성. 명령어를 해석하고 연산을 수행합니다.

핵심 구성

메모리

데이터와 프로그램(명령어)을 동일한 공간에 저장합니다. 주소로 접근합니다.

핵심 구성

입출력 장치

사용자와 컴퓨터 간 데이터를 주고받는 인터페이스입니다.

핵심 구성

버스

CPU, 메모리, 입출력 장치를 연결하는 데이터 통로입니다. 데이터/주소/제어 버스로 구분됩니다.

프로그램 내장 방식 — 명령어를 메모리에 저장해두고 순서대로 실행합니다. 하드웨어 변경 없이 소프트웨어만 바꿔 다른 작업을 수행할 수 있습니다.
순차 실행 (Sequential Execution) — 명령어는 기본적으로 메모리 주소 순서대로 실행됩니다. 분기(Branch) 명령어가 있을 때만 순서를 바꿉니다.
폰 노이만 병목 (Von Neumann Bottleneck) — CPU와 메모리 사이의 단일 버스가 성능 제약이 됩니다. 캐시 메모리, 파이프라이닝이 이 문제를 완화합니다.
하버드 구조와의 차이 — 하버드 구조는 명령어 메모리와 데이터 메모리를 분리합니다. 현대 CPU는 내부적으로 하버드 구조를 쓰고 외부적으로 폰 노이만 구조를 씁니다.
