CPU 구성 요소

태그

CPU(Central Processing Unit)는 컴퓨터의 두뇌입니다. 크게 ALU(산술논리연산장치), CU(제어장치), 레지스터(Register) 세 가지로 구성되며, 이들이 협력해 명령어를 해석하고 연산을 수행합니다.

핵심 구성

ALU — 산술논리연산장치

덧셈·뺄셈·곱셈 등 산술 연산과 AND·OR·NOT 등 논리 연산을 수행합니다. CPU의 실제 계산을 담당하는 핵심 부품입니다.

핵심 구성

CU — 제어장치

명령어를 해석하고 CPU 각 부품에 제어 신호를 보냅니다. 전체 연산 흐름을 지휘하는 지휘자 역할입니다.

핵심 구성

레지스터

CPU 내부의 초고속 임시 저장 공간입니다. PC, IR, MAR, MDR, ACC 등 역할에 따라 구분됩니다.

핵심 구성

내부 버스

CPU 내부 구성 요소들 사이의 데이터 통로입니다. ALU, CU, 레지스터를 연결합니다.

PC (Program Counter) — 다음에 실행할 명령어의 메모리 주소를 저장합니다. 명령어 실행 후 자동으로 증가합니다.
IR (Instruction Register) — 현재 실행 중인 명령어를 저장합니다. CU가 이 명령어를 해석해 제어 신호를 생성합니다.
MAR (Memory Address Register) — 메모리에서 읽거나 쓸 주소를 임시 저장합니다. 주소 버스와 연결됩니다.
MDR (Memory Data Register) — 메모리에서 읽어온 데이터 또는 메모리에 쓸 데이터를 임시 저장합니다. 데이터 버스와 연결됩니다. MBR(Memory Buffer Register)이라고도 부르며 동일한 레지스터입니다.
ACC (Accumulator) — ALU 연산 결과를 저장하는 레지스터입니다. 연산의 중간 결과를 누적합니다.
