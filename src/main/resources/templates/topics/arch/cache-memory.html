캐시 메모리

태그

캐시 메모리(Cache Memory)는 CPU와 주기억장치(RAM) 사이에 위치한 초고속 임시 저장 공간입니다. CPU가 자주 쓰는 데이터를 미리 담아두어 메모리 접근 속도 차이를 극복하고 전체 성능을 끌어올립니다.

핵심 개념

캐시 히트 (Cache Hit)

CPU가 요청한 데이터가 캐시에 있는 경우입니다. 메인 메모리 접근 없이 캐시에서 바로 데이터를 가져오므로 매우 빠릅니다.

핵심 개념

캐시 미스 (Cache Miss)

CPU가 요청한 데이터가 캐시에 없는 경우입니다. 메인 메모리에서 데이터를 가져온 뒤 캐시에 적재(Load)합니다.

핵심 개념

지역성 원리

시간 지역성(방금 쓴 데이터를 곧 다시 씀)과 공간 지역성(인접한 주소의 데이터를 곧 씀)을 활용해 캐시 효율을 높입니다.

핵심 개념

캐시 계층 (L1 / L2 / L3)

L1은 가장 빠르고 작으며 CPU 코어에 직접 붙어있습니다. L2·L3로 갈수록 느리지만 용량이 커집니다.

핵심 개념

교체 정책 (LRU)

캐시가 가득 찼을 때 가장 오랫동안 사용되지 않은 데이터를 제거합니다. LRU(Least Recently Used)가 가장 널리 쓰입니다.

핵심 개념

쓰기 정책

Write-Through는 캐시와 메모리를 동시에 갱신합니다. Write-Back은 캐시만 먼저 갱신하고 나중에 메모리에 반영합니다.

히트율 (Hit Rate) — 전체 메모리 접근 중 캐시 히트 비율입니다. 히트율이 높을수록 성능이 좋으며, 현대 CPU는 90% 이상을 목표로 합니다.
블록 (Block / Cache Line) — 캐시는 데이터를 바이트 단위가 아닌 블록(보통 64바이트) 단위로 메모리에서 가져옵니다. 공간 지역성 활용의 핵심입니다.
직접 매핑 (Direct Mapped) — 메모리 블록이 캐시의 고정된 한 슬롯에만 들어갈 수 있습니다. 구조가 단순하지만 충돌 미스가 발생할 수 있습니다.
연관 매핑 (Fully Associative) — 메모리 블록이 캐시의 어느 슬롯에든 들어갈 수 있습니다. 충돌 미스가 없지만 검색 비용이 높습니다.
세트 연관 매핑 (Set Associative) — 직접·연관 매핑의 절충안입니다. 캐시를 세트로 나누고 각 세트 내에서 연관 매핑을 적용합니다.
